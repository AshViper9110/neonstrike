ローカルサーバーから起動してください

index.html を直接開くと、ブラウザのセキュリティ制限（file://）により CSS と JavaScript が読み込まれません。そのため画面が崩れたり、操作できなくなります。

1. フォルダ内の start-game.bat をダブルクリック
2. ブラウザが自動で開きます（http://localhost:5173）

手動で起動する場合

npm.cmd install → npm.cmd run dev
